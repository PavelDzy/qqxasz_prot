# Защищённая страница с прототипами

Статический сайт для GitHub Pages. Файлы игр и каталог лежат в `docs/` зашифрованными (AES-256-GCM), ключ получается из логина и пароля (PBKDF2, 600 000 итераций). После входа Service Worker расшифровывает файлы прямо в браузере.

## Публикация
1. Создать репозиторий на GitHub и запушить эту папку. `source/` исключена через `.gitignore`, в репозиторий попадёт только `docs/`.
2. Settings → Pages → Deploy from a branch → `main` / `/docs`.

## Команды
- `node source/build.mjs` — пересобрать `docs/` (игры берутся из zip-архивов по путям в `source/games.json`).
- `node source/test.mjs` — проверить сайт в Chromium и WebKit.
- `node source/test.mjs --covers` — снять обложки игр в `source/app/covers/`, затем снова запустить сборку.

## Сменить логин или пароль
Изменить `login` и `password` в `source/.secrets.json`, запустить сборку и запушить `docs/`. Все файлы перешифруются новым ключом, а вход на всех устройствах сбросится.

## Добавить или обновить игру
Отредактировать `source/games.json` (`slug`, `title`, `genre`, `text`, `zip`), запустить сборку, снять обложку и запушить `docs/`.

## Ограничения
- Логин и пароль один на всех, отдельных учётных записей нет.
- Попытки входа никто не ограничивает: шифротекст публичен, и подбирать пароль можно на своём компьютере. Стойкость держится на длинном случайном пароле, короткий ставить нельзя.
- Старые коммиты остаются в истории git и открываются старым паролем.
- Нужен браузер с Service Worker: в некоторых приватных режимах сайт не откроется.
- `source/` нигде не хранится, кроме этого компьютера. `.secrets.json` не публиковать.
